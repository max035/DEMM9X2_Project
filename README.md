# DEMM9X2_Project
Debt Market Modelling - Project Assignment 1

Overview
This project presents a comparative corporate finance and investment analysis of four major South African retailers: Pick n Pay, Shoprite, Woolworths, and SPAR. The analysis covers the 2023-2025 period and evaluates financial performance, debt financing, interest-rate exposure, cost of capital, capital structure, and equity valuation.

Key Areas of Analysis

•	Financial statement and ratio analysis

•	Corporate debt and fixed-income financing

•	South African interest-rate environment

•	Cost of debt and cost of equity

•	Capital structure and WACC

•	Relative equity valuation using EV/EBITDA, P/E, and P/S

•	Investment attractiveness and recommendations

The project combines financial-statement data, market data, share-price data, government bond yields, and company financing information to assess the financial strength, risk, valuation, and investment prospects of each retailer.
Project Deliverables

•	Report: Detailed analysis, methodology, results, and recommendations

•	Excel workbook: Supporting financial data and calculations

•	Python script:  Financial Ratio Computation and Visualization

•	GitHub repository: Project files and supporting analysis
